# Fixture licences

Shared golden data used by the JS tests, Playwright and pytest. Only KiCad demo boards, magpie's
synthetic boards and data generated here belong in `fixtures/`; no company or customer designs.
(`test/fixtures/` has its own README for the JS-only inputs.)

| path | what | source | licence |
|---|---|---|---|
| `royalblue54L_feather/kicad/RoyalBlue54L-Feather.kicad_pcb` | KiCad demo board (Lords Boards' RoyalBlue54L Feather, nRF54L15, 8 copper layers) | KiCad's `demos/royalblue54L_feather` as shipped with KiCad 10.0.6 (board file written by pcbnew 9.0), unmodified | CERN-OHL-P v2, see `royalblue54L_feather/LICENSE` (copied from the demo folder) |
| `royalblue54L_feather/fab/` | Gerbers, gbrjob, Excellon drills and pos file of that board | generated with kicad-cli 10.0.6 by `royalblue54L_feather/make_fab.sh` | derived from the board above: CERN-OHL-P v2 |
| `royalblue54L_feather/board.json` | golden `boarddd/board@1` model of that board | generated by `royalblue54L_feather/make_board.py` | derived from the board above: CERN-OHL-P v2 |
| `royalblue54L_feather/*.py`, `*.sh` | scripts | written for boarddd | MIT (this repository) |
| `model/minimal.json`, `model/cases.json` | a small hand-written board and the validator cases | written for boarddd | MIT (this repository) |
| `impedance/cases.json`, `impedance/make_cases.mjs` | shared impedance cases: reference values (Polar's published Si9000 cases, HFSS values published in Ttl/js_2d_fields' tests, scipy and scikit-rf evaluations) and generated inputs/results | written for boarddd; reference numbers cited per source in the file | MIT (this repository) |
| `impedance/qs-sweep.json` | 886 quasi-static field solutions used to fit and check boarddd's impedance corrections | numbers computed locally with hforsten's solver (Ttl/js_2d_fields, GPL-3.0) used as a tool; no code from it is in boarddd | MIT (this repository) |
