# Examples

`npm run serve`, then open http://127.0.0.1:8417/examples/.

- `index.html`: a KiCad demo board (KiCad demo data, from KiCad's own `demos/` folder, GPL/CC as
  shipped by KiCad) from its gerbers + drill files + GLB. Coming in phase 1.

The demo data is exported with `scripts/export-demo.sh` (kicad-cli) into `examples/data/`.
